# 09_LVGL_V9_Test

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Shows an LVGL 9 interface on the reflective LCD.

## Hardware Required

- ESP32-S3-RLCD-4.2 development board

## How to Run

```bash
idf.py set-target esp32s3 build flash monitor
```

## Expected Result

The display alternates between two images every 1.5 seconds.

None yet.
