# ESPHome Example Configurations

[中文](README_ZH.md)

Ready-to-use ESPHome YAML for the ESP32-S3-RLCD-4.2. Define `wifi_ssid` / `wifi_password` in your `secrets.yaml` before flashing.

| File | Description | Hardware |
| --- | --- | --- |
| [esp32-s3-rlcd-42-sensor.yaml](./esp32-s3-rlcd-42-sensor.yaml) | Sensor dashboard: temp & humidity, battery level, progress bar | Display / SHTC3 / battery ADC / BOOT + KEY |
| [esp32-s3-rlcd-42-speaker.yaml](./esp32-s3-rlcd-42-speaker.yaml) | Sensor dashboard + speaker RTTTL ringtone test | Display / SHTC3 / battery ADC / speaker |
| [esp32-s3-rlcd-42-wake-word.yaml](./esp32-s3-rlcd-42-wake-word.yaml) | On-device wake word detection with counter display | Display / dual microphone |

## Usage

1. In the ESPHome dashboard, **NEW DEVICE → Skip** to create an empty device.
2. Click **EDIT** on the device card and paste the YAML contents.
3. Replace `REPLACE_WITH_YOUR_KEY` / `REPLACE_WITH_YOUR_PASSWORD` with the values generated by the wizard, or create a new device and copy its credentials.
4. Click **SAVE → INSTALL**. First flash via USB; subsequent updates can use **Wirelessly** (OTA).
